# 🌿 Greenden - Plant Store Website

Greenden is a modern and responsive plant store website designed to provide a clean and attractive online shopping experience for plant lovers. The project focuses on creating a simple, user-friendly interface using **HTML5** and **Tailwind CSS**.

The website is designed with a responsive layout so that the content adapts smoothly to different screen sizes, including desktops, tablets, and mobile devices.

## 📌 About the Project

Greenden is a frontend website project created to practice and demonstrate modern web design using **HTML5** and **Tailwind CSS**.

The website presents plants and plant-related products through a clean layout with attractive product cards, navigation sections, and a contact page. Tailwind CSS utility classes are used to build the layout, spacing, typography, colors, and responsive design without relying on a separate CSS framework.

This project helped improve my understanding of responsive web development, HTML page structure, Tailwind CSS utilities, and creating consistent user interfaces across multiple pages.

## 📱 Responsive Design

The website is designed to provide a consistent experience across:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

Tailwind CSS responsive utility classes are used to adjust layouts, spacing, text sizes, and product grids according to the screen size.
